# 計算機功能規劃

## 目標
製作一個簡單的網頁計算機，能夠進行加法、減法、乘法與除法的四則運算。

---

## 功能清單

### 使用者介面（UI）
- [ ] 數字按鈕（0–9）
- [ ] 運算符號按鈕（+、-、×、÷）
- [ ] 等號按鈕（=）：顯示計算結果
- [ ] 清除按鈕（C）：清除目前輸入
- [ ] 顯示區：顯示輸入的算式與結果

### 計算邏輯
- [ ] 可輸入多位數（例如輸入 123 而非只限個位數）
- [ ] 支援基本運算：加、減、乘、除
- [ ] 支援連續運算（例如 5 + 3 × 2）
- [ ] 按下等號後進行正確計算並顯示結果
- [ ] 處理除以 0 的錯誤狀況（顯示錯誤訊息）

### 額外功能（可選）
- [ ] 支援鍵盤輸入
- [ ] 支援小數點輸入與運算
- [ ] 響應式設計（適應手機與電腦）

---

## 技術規劃
- 使用 React 製作元件
- JavaScript 負責運算邏輯處理
- CSS 或 Tailwind 設計介面樣式

---

## 備註
- 介面需簡單直觀，適合初學者使用
- 先完成基本功能，再考慮額外功能
